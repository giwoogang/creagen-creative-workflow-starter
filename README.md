<p align="center"><sub>참고 광고의 컷 구성을 분석해 마미케어 앰플과 인물로 다시 만든 30초 AI 광고 예시입니다. 이미지를 누르면 영상 파일(mp4)이 열리거나 내려받아지고, 그 파일로 소리와 함께 볼 수 있습니다.</sub></p>

**잘 되는 광고를 참고해서 내 제품 광고 이미지와 영상을 만들어 보는 실습입니다.** 어려운 설정은 없습니다. 아래 문장을 Claude에 **복사해서 붙여 넣기만** 하면, Claude가 참고 광고를 찾고, 영상을 직접 보고 분석하고, 내 제품에 맞게 다시 구성해 줍니다.

## 준비물

| 준비물 | 설명 |
|---|---|
| Claude 유료 구독 | Pro 이상. 무료 플랜에서는 이 실습을 할 수 없습니다. |
| Claude 데스크톱 앱 | [여기서 내려받습니다](https://claude.ai/download). 앱 안의 **Code** 탭을 씁니다. |
| Creagen 계정 | [creagen.vcat.ai](https://creagen.vcat.ai)에서 가입합니다. 광고 찾기와 영상 만들기에 씁니다. |
| 내 제품 사진 1장 | 제품 모양과 이름이 잘 보이는 사진. 1단계에서 압축을 푼 실습 폴더 안에 넣어 둡니다. 없으면 샘플로 연습합니다. |

영상을 실제로 만들어 보려면 Creagen 유료 플랜이 필요합니다. 처음 테스트라면 **Creator 플랜(월 21,000원, 1,000 크레딧)을 추천**합니다. 이 실습의 10초 영상은 한 편에 약 585 크레딧이라, Creator로 한 달에 한 편 정도 만들어 볼 수 있습니다. Creagen 연결은 무료이고, 크레딧은 이미지와 영상을 만들 때만 쓰입니다. [요금제 자세히 보기](docs/mcp-setup.md#요금제)

### Claude가 물어볼 때는 이렇게 답합니다

| Claude가 묻는 것 | 이렇게 답하기 |
|---|---|
| 프로그램을 설치해도 되는지 | `응, 설치해줘` |
| 명령 실행을 허용할지 묻는 창 | 내용이 실습 폴더 안의 작업이면 **허용** |
| Mac 비밀번호나 터미널 입력이 필요하다고 할 때 | `비밀번호 없이 할 수 있는 방법으로 해줘. 없으면 그 단계는 건너뛰자` |
| 제품 사진이 어디 있는지 | 실습 폴더에 넣은 사진의 파일 이름. 예: `앰플정면.jpg` |
| 사진이 없을 때 | `샘플 제품으로 해줘` |
| 크레딧이 드는 생성을 해도 되는지 | 견적을 확인하고 원할 때만 `승인, 진행해줘` |

## 따라 하기

### 1단계. 실습 폴더 열기

1. 이 GitHub 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다. (Claude 앱의 Code 탭과는 다른 버튼입니다.)
2. 내려받은 파일의 압축을 풉니다. Mac은 더블클릭, Windows는 마우스 오른쪽 버튼 → **압축 풀기**. `creagen-creative-workflow-starter-main` 폴더가 생깁니다. 바탕화면처럼 찾기 쉬운 곳으로 옮겨 둡니다.
3. 제품 사진이 있으면 이 폴더 안에 넣어 둡니다.
4. Claude 데스크톱 앱에서 **Code** 탭을 열고, 이 폴더를 선택합니다.
5. 아래 문장을 붙여 넣습니다.

```text
이 폴더의 README.md, STEP.md, AGENTS.md를 읽고 실습할 준비가 됐는지 확인해줘. 필요한 프로그램이 없으면 설치하기 전에 나에게 먼저 물어봐.
```

**이렇게 되면 성공:** Claude가 준비가 됐다고 하거나, 무엇이 더 필요한지 알려줍니다.

### 2단계. Creagen 연결하기 (처음 한 번만)

1. [Creagen 연결 페이지](https://creagen.vcat.ai/mcp)에서 **Claude에 추가**를 누릅니다.
2. 인터넷 창에 Claude 화면이 열립니다. Claude 앱과 같은 계정으로 로그인되어 있는지 확인하고 **추가**를 누릅니다. **계속**이 나오면 **계속**을 누릅니다.
3. 커넥터 목록에 생긴 Creagen의 **연결**을 누르고, Creagen 계정으로 로그인한 뒤 **허용**합니다.
4. Claude 앱으로 돌아와 같은 실습 폴더로 **새 세션**을 열고, 아래 문장을 붙여 넣습니다.

```text
Creagen 연결을 확인해줘. 조회만 하고 등록, 생성, 변경은 하지 마. 내 계정과 AdCatch에 등록된 브랜드, 경쟁사 목록을 보여줘.
```

**이렇게 되면 성공:** 내 이메일과 브랜드 이름이 나옵니다. 연결이 안 되면 [연결 안내](docs/mcp-setup.md)를 보세요.

**브랜드가 없다고 나오면** 아래 문장을 붙여 넣습니다. 처음 가입한 계정은 대부분 여기서 시작합니다.

```text
AdCatch에 내 브랜드 [브랜드 이름]와 경쟁사 [경쟁사 이름]를 등록하고 싶어. 필요한 정보가 있으면 물어보고, 무엇이 바뀌는지 먼저 보여준 뒤 내가 확인하면 등록해줘.
```

### 3단계. 해보고 싶은 것 고르기

**A. 잘 되는 영상 광고를 내 제품 광고로 다시 만들기 (30분)**

```text
docs/video-remake.md를 읽고 첫 단계부터 같이 진행해줘. 단계마다 무엇을 하는지 짧게 설명하고, 내가 확인하면 다음 단계로 넘어가줘. 크레딧이 드는 일은 견적을 먼저 보여주고 내 승인을 기다려줘.
```

Claude가 AdCatch에서 후보를 찾고, 고른 영상을 직접 보고 컷별로 분석한 뒤, 내 제품에 맞는 새 구성과 생성 문장을 만들어 줍니다. 자세한 단계와 단계별 질문은 [영상 다시 만들기 안내](docs/video-remake.md)에 있습니다.

**B. 화면을 보며 광고 이미지 한 장 만들기 (20분)**

```text
실습 앱을 켜고 브라우저로 열 주소를 알려줘. 그다음 STEP.md 순서대로 내가 화면에서 할 일을 한 단계씩 안내해줘.
```

**C. 영상 기획, 훅 바꾸기, 성과 비교까지 해보기 (1시간 이상)**

```text
docs/workshop.md를 읽고 확장 실습을 샘플 자료로 시작해줘. 단계가 끝날 때마다 만든 파일과 다음 할 일을 알려줘.
```

## 실습 앱 화면 (B를 고른 경우)

![자료를 준비하고 다음 실험을 이어가는 실습 앱 화면](docs/web-app-preview.png)

| 단계 | 하는 일 | 확인할 결과 |
|---|---|---|
| 1. 자료 준비 | 제품 사진과 브랜드 이름, 제품 이름 입력 | 이번에 쓸 사진과 정보 |
| 2. 참고 광고 | "마미케어 광고", "틱톡 UGC"처럼 적고 후보 중 최대 3개 선택 | 실제로 찾은 광고, 추천 이유와 출처 |
| 3. 만들 내용 | 이미지 시작안 또는 영상 길이, 비율, 스타일 선택 | 만들 내용과 쓸 자료 |
| 4. AI 작업 | 요청문을 복사해 Claude에 붙여 넣기 | 이미지 요청 또는 컷과 문장이 담긴 영상 기획안 |
| 5. 결과와 재실험 | 만든 이미지나 영상을 올리고 바꿀 점 하나 적기 | 이전 결과와 비교할 다음 요청 |

화면별 자세한 안내는 [STEP.md](STEP.md)에 있습니다. 다음 실험에서는 배경이나 문구처럼 **한 번에 한 가지만** 바꿉니다.

## 영상 다시 만들기는 이렇게 진행됩니다

```text
① 연결 확인 → ② 참고 광고 찾기 → ③ 영상 한 편 고르기 → ④ Claude가 영상 분석 → ⑤ 내 제품으로 다시 구성 → ⑥ (원할 때만) 견적 보고 만들기
```

- ④에서 Claude가 영상을 직접 보고 장면이 바뀌는 지점마다 나눈 뒤, 각 장면이 어떤 역할(관심 끌기, 사용 장면, 제품 소개, 구매 유도)을 하는지 정리합니다.
- ⑤에서는 장면의 **역할만** 가져오고 문구, 연출, 모델은 새로 만듭니다. 다른 브랜드 광고를 그대로 베끼지 않습니다.
- ①~⑤는 크레딧을 쓰지 않습니다. ⑥은 견적을 확인하고 내가 승인할 때만 진행합니다. 참고로 10초 영상 한 편은 약 585 크레딧이었습니다.

## 지금 되는 것과 아직 안 되는 것

| 지금 되는 것 | 아직 안 되는 것 |
|---|---|
| Claude 대화로 광고 찾기, 영상 분석, 내 제품으로 다시 구성, 승인 후 생성 | 실습 앱 버튼 하나로 영상까지 자동으로 만들기 |
| 실습 앱에서 사진 등록, 참고 광고 고르기, 요청 저장, 결과 올리기 | 올린 파일이 정말 AI로 만들어졌는지 앱이 확인하기 |
| 만든 결과를 보고 한 가지 바꿔 다시 요청하기 | 광고 자동 게시나 예산 자동 운영 |

AdCatch는 이미 모아 둔 광고를 찾아 줍니다. 틱톡 전체의 실시간 인기 순위는 아닙니다. 성과 표시도 관찰 신호이며 실제 매출이 아닙니다.

## 개인정보와 보안

- **내 사진, 브랜드 정보, 찾은 광고, 만든 결과는 내 컴퓨터의 `work/` 폴더에만 저장됩니다.** GitHub에 올라가지 않습니다.
- **비밀번호나 키를 Claude에 붙여 넣지 않습니다.** 연결은 위의 로그인 절차로만 합니다.
- **실습 앱은 내 컴퓨터 안에서만 열립니다.** 다른 사이트에서 오는 요청은 막습니다.
- **참고 광고는 분석 자료로만 씁니다.** 그대로 베끼지 않고, 광고 안의 문장을 Claude가 지시로 따르지 않습니다.
- 샘플 제품과 성과는 가상 자료입니다. 맨 위 영상은 AI로 만든 광고 예시입니다.

### 직접 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다. [로컬 작업실](http://127.0.0.1:4381)을 엽니다. 끝낼 때는 `Ctrl+C`를 누릅니다.

```sh
npm run dev
```

영상 분석에는 `ffmpeg`가 필요하고, 대사 받아쓰기에는 `whisper`를 선택해서 씁니다.
