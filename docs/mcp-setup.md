# Claude Code에 Creagen 연결하기 (AdCatch 포함)

**Creagen 커넥터 하나만 연결하면 AdCatch 광고 검색, Creagen 이미지와 영상 생성, AdAgent 광고 운영 도구를 Claude 대화에서 함께 쓸 수 있습니다.** AdCatch를 따로 연결할 필요는 없습니다. 처음 연결은 5분 정도 걸립니다.

## 준비물

| 준비할 것 | 설명 |
|---|---|
| Claude 유료 플랜 | Claude Code는 Pro, Max, Team, Enterprise 플랜이나 Console 계정에서 쓸 수 있습니다. 무료 플랜에는 Claude Code가 없습니다. |
| Claude Code | Claude 데스크톱 앱의 Code 탭이나 터미널의 `claude`를 씁니다. 이 프로젝트 폴더를 열어 둡니다. |
| Creagen 계정 | [creagen.vcat.ai](https://creagen.vcat.ai)에서 가입합니다. AdCatch와 같은 vcat 계정입니다. |
| Creagen 요금제 | 연결은 무료입니다. 이미지나 영상을 생성하려면 크레딧이 필요합니다. 결제는 테스트 목적이라면 Creator 플랜을 추천합니다. [요금제](#요금제)를 보세요. |

## 연결하기

### 방법 1. Claude에 커넥터로 추가 (추천)

한 번 추가하면 Claude 웹, 데스크톱 앱, Claude Code에서 함께 씁니다. 명령어를 입력할 필요가 없습니다.

1. [Creagen MCP 안내 페이지](https://creagen.vcat.ai/mcp)를 엽니다.
2. **Claude에 추가** 버튼을 누릅니다. Claude의 커넥터 추가 화면이 열리고 이름(Creagen)과 주소가 미리 채워져 있습니다.
3. 내용을 확인하고 **계속**, **추가**를 차례로 누릅니다.
4. **연결**을 누르고 Creagen 계정으로 로그인한 뒤 **허용**합니다.

이름과 주소가 비어 있으면 Claude 설정의 **사용자 정의 → 커넥터 → 추가 → 커스텀 커넥터 추가**에서 직접 넣습니다.

| 항목 | 값 |
|---|---|
| 이름 | `Creagen` |
| 커넥터 주소 | `https://agent.vcat.ai/api/mcp/creagenOfficialMCPServer/mcp` |

- `https://creagen.vcat.ai/mcp`는 안내 페이지 주소입니다. 커넥터 주소 칸에 넣으면 연결되지 않습니다.
- 회사 Team이나 Enterprise 플랜이라면 조직 Owner만 커넥터를 추가할 수 있습니다. Owner가 조직 설정에 Creagen을 추가하면 구성원은 커넥터 화면에서 **연결**만 누르고 각자 로그인합니다.

**Claude Code에서 확인하기**

1. Claude Code에서 이 프로젝트 폴더를 엽니다.
2. 입력창에 `/mcp`를 입력하고 Enter를 누릅니다.
3. 목록에서 Creagen(claude.ai 표시가 붙어 있습니다)이 연결됨인지 봅니다. 로그인이 필요하다고 나오면 고르고 로그인합니다. 한 번도 쓰지 않은 커넥터는 목록 아래 **사용하지 않은 커넥터 보기**(Show unused connectors)에 접혀 있을 수 있습니다.
4. 목록에 없으면 **새 세션**을 열고 다시 확인합니다. 세션은 시작할 때 커넥터 목록을 불러옵니다.

Claude에 추가한 커넥터는 **Claude 구독 계정으로 로그인한 Claude Code**에만 나타납니다. 안 보이면 `/status`로 로그인 방법을 확인하고, API 키로 로그인되어 있다면 `/login`으로 Claude 계정을 고릅니다.

### 방법 2. 터미널 명령으로 추가

API 키로 Claude Code를 쓰거나, 회사 플랜이라 커넥터를 추가할 권한이 없거나, 터미널이 편하다면 이 방법을 씁니다. `claude` 세션 안이 아니라 **터미널**에서 이 프로젝트 폴더로 이동해 실행합니다.

```bash
claude mcp add --transport http creagen https://agent.vcat.ai/api/mcp/creagenOfficialMCPServer/mcp
```

- 추가 직후 `claude mcp list`에 `! Needs authentication`이 보이는 것이 정상입니다.
- `claude`를 실행하고 `/mcp` → **creagen** → Enter → **Authenticate**를 누르면 브라우저에서 Creagen 로그인과 허용이 진행됩니다.
- 이 명령은 이 폴더에서만 쓰도록 등록합니다. 모든 폴더에서 쓰려면 `--scope user`를 붙입니다.
- 지울 때는 `claude mcp remove creagen`을 실행합니다.

**방법 1과 방법 2 중 하나만 씁니다.** 같은 주소를 둘 다 등록하면 방법 2가 우선하고 Claude 커넥터는 숨겨집니다. 방법 2 쪽이 로그인 전이면 계속 "인증 필요"로 남습니다.

## 연결 확인

Claude Code 대화창에 아래 문장을 붙여 넣습니다. 조회만 하므로 크레딧을 쓰지 않습니다.

```text
Creagen 연결을 확인해줘. 읽기 전용 도구만 쓰고 등록, 생성, 변경은 하지 마.
내 계정 → AdCatch 워크스페이스 → 브랜드 → 경쟁사 → 광고 검색 5건 → 광고 1건 상세 순서로 확인해줘.
```

| 순서 | Claude가 확인하는 것 | 이렇게 나오면 정상 |
|---|---|---|
| 1 | 연결된 계정 | 내 이메일 |
| 2 | AdCatch 워크스페이스 | 1개 이상, 선택된 워크스페이스 표시 |
| 3 | 등록된 브랜드 | 1개 이상 |
| 4 | 브랜드의 경쟁사 | 목록이 나옴. 0개여도 연결은 정상 |
| 5 | 광고 검색 | 광고 목록과 전체 건수 |
| 6 | 광고 1건 상세 | 훅, 화면 구성, 원본 미디어 정보 |

- 1~3번까지 되면 연결은 정상입니다.
- 6번까지 되면 AdCatch 광고 조회도 정상입니다.
- 브랜드가 0개면 [adcatch.vcat.ai](https://adcatch.vcat.ai)에서 내 브랜드와 경쟁사를 먼저 등록합니다.

연결이 끝나면 [참고 영상 한 편을 내 제품 광고로 다시 만들기](video-remake.md)나 웹앱 [STEP 2](../STEP.md#step-2-참고-광고)로 넘어갑니다.

## 요금제

**결제는 테스트 목적이라면 Creator 플랜을 추천드립니다.** 커넥터 연결은 무료이고, 이미지와 영상을 생성할 때만 크레딧이 쓰입니다. Creator는 가장 낮은 금액으로 월 1,000 크레딧을 받아 연결 확인과 시험 생성에 알맞습니다.

| 플랜 | 월간 결제 | 연간 결제 (40% 할인) | 월 크레딧 | 생성량 안내 (모델에 따라 다름) |
|---|---|---|---|---|
| **Creator (추천)** | 21,000원 | 월 12,600원 (연 151,200원) | 1,000 | 영상 약 30개 이상, 이미지 약 250개 이상 |
| Creator Pro | 49,000원 | 월 29,400원 (연 352,800원) | 2,500 | 영상 약 80개 이상, 이미지 약 650개 이상 |
| Enterprise | 영업팀 문의 | 영업팀 문의 | 협의 | 협의 |

크레딧 감을 잡기 위한 실제 견적 예시입니다 (2026년 10월 23일, 크레딧 차감 없는 견적 조회).

| 만들 것 | 견적 |
|---|---|
| Seedance 2.5 참조 영상 10초, 1:1, 720p | 585 크레딧 |
| 같은 설정 5초 | 295 크레딧 |
| 같은 설정 10초, 1080p | 1,440 크레딧 |

- **테스트는 월간 결제로 시작합니다.** 연간 할인은 런칭 프로모션이지만 1년 단위 결제입니다.
- **추가 크레딧(크레딧 팩)은 Creator Pro 구독자만 살 수 있습니다.** Creator에서 크레딧이 모자라면 다음 달을 기다리거나 업그레이드합니다.
- 기술 문제로 생성이 실패하면 차감된 크레딧은 자동으로 복구됩니다.
- 유료 플랜으로 만든 이미지와 영상은 상업적으로 쓸 수 있습니다. 타인의 초상권, 상표권, 저작권은 따로 주의합니다.
- 부가세 포함 여부와 플랜별 AdCatch 이용 범위는 요금 페이지에 적혀 있지 않습니다. 결제 화면이나 Creagen 고객센터에서 확인합니다.
- 가격은 2026년 10월 23일 [요금제 페이지](https://creagen.vcat.ai/pricing) 기준입니다. 결제 전에 최신 가격을 확인하세요.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| `/mcp` 목록에 Creagen이 없음 | 새 세션을 열고 다시 확인합니다. 사용하지 않은 커넥터 목록도 펼쳐 봅니다. 그래도 없으면 `/status`로 Claude 구독 계정 로그인인지 확인합니다. |
| 계속 "인증 필요"로 나옴 | `/mcp`에서 Creagen을 고르고 로그인합니다. Creagen 웹사이트에만 로그인하면 Claude에는 권한이 넘어가지 않습니다. |
| 커넥터를 추가했는데 Claude Code에서 안 보임 | 방법 2로도 같은 주소를 등록했는지 `claude mcp list`로 확인합니다. 둘 중 하나를 지웁니다. |
| 브라우저 로그인 창이 안 열림 | 화면에 나온 주소를 직접 엽니다. 로그인 후 돌아오지 않으면 주소창의 주소 전체를 Claude Code에 붙여 넣습니다. |
| 401 또는 인증 오류 | 로그인이 만료된 것입니다. `/mcp`에서 다시 로그인합니다. |
| 브랜드가 0개 | AdCatch에 브랜드가 등록되지 않았습니다. adcatch.vcat.ai에서 등록합니다. |
| 검색 결과가 0건 | 조건이 너무 좁거나 아직 수집되지 않은 광고입니다. 조건을 하나씩 줄입니다. |
| 다른 팀 자료가 보임 | 워크스페이스가 여러 개입니다. 어느 워크스페이스를 쓸지 Claude에게 지정합니다. |

## 안전하게 쓰기

- **생성은 견적부터.** 생성 도구는 크레딧을 씁니다. Claude가 견적과 잔여 크레딧을 먼저 보여주고 내가 승인한 뒤 생성하게 요청합니다.
- **AdAgent는 실제 광고를 바꿉니다.** 캠페인 상태, 일 예산 변경, 광고 등록 도구는 실제 집행과 비용에 영향을 줍니다. 명확히 요청할 때만 쓰게 합니다.
- **AdCatch 등록 도구는 계정 설정을 바꿉니다.** 브랜드와 경쟁사 등록, 계정 연결, URL 분석 시작은 필요할 때만 요청합니다.
- **성과 신호는 매출이 아닙니다.** AdCatch의 성과 등급은 관찰 신호이며 실제 매출이나 ROAS가 아닙니다.
- **키와 토큰을 대화에 붙여 넣지 않습니다.** 인증은 위의 로그인 절차로만 합니다.
- 실습 참가자는 각자 자기 Creagen 계정으로 로그인합니다. 보이는 워크스페이스, 브랜드, 경쟁사도 각자 계정 기준입니다.
