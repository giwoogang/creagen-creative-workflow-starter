# Claude 앱에 Creagen 연결하기 (AdCatch 포함)

**Creagen 하나만 연결하면 AdCatch 광고 찾기, Creagen 이미지와 영상 만들기, AdAgent 광고 운영 도구를 Claude 대화에서 함께 쓸 수 있습니다.** AdCatch를 따로 연결할 필요는 없습니다. 처음 연결은 5분 정도 걸립니다.

## 준비물

| 준비할 것 | 설명 |
|---|---|
| Claude 유료 구독 | Pro 이상. 무료 플랜에서는 이 실습을 할 수 없습니다. |
| Claude 데스크톱 앱 | [여기서 내려받습니다](https://claude.ai/download). 앱 안의 **Code** 탭에서 실습 폴더를 열어 둡니다. |
| Creagen 계정 | [creagen.vcat.ai](https://creagen.vcat.ai)에서 가입합니다. AdCatch도 같은 계정으로 씁니다. |
| Creagen 요금제 | 연결은 무료입니다. 이미지나 영상을 만들 때만 크레딧이 듭니다. 처음 테스트라면 Creator 플랜을 추천합니다. [요금제](#요금제)를 보세요. |

## 연결하기

### 방법 1. 버튼으로 추가 (추천)

한 번 추가하면 Claude 웹, Claude 앱, Code 탭에서 함께 씁니다.

1. [Creagen 연결 페이지](https://creagen.vcat.ai/mcp)를 엽니다.
2. **Claude에 추가** 버튼을 누릅니다.
3. 인터넷 창에 Claude의 커넥터 추가 화면이 열립니다. 이름(Creagen)과 주소가 미리 채워져 있습니다. Claude 앱과 같은 계정으로 로그인되어 있는지 확인하고 **추가**를 누릅니다. **계속**이 나오면 **계속**을 누릅니다.
4. 커넥터 목록에 생긴 Creagen의 **연결**을 누르고, Creagen 계정으로 로그인한 뒤 **허용**합니다.

이름과 주소가 비어 있으면 아래 값을 직접 넣습니다. Claude 설정의 **사용자 정의 → 커넥터 → 추가 → 커스텀 커넥터 추가**에서 넣을 수 있습니다.

| 항목 | 값 |
|---|---|
| 이름 | `Creagen` |
| 커넥터 주소 | `https://agent.vcat.ai/api/mcp/creagenOfficialMCPServer/mcp` |

- `https://creagen.vcat.ai/mcp`는 안내 페이지 주소입니다. 커넥터 주소 칸에 넣으면 연결되지 않습니다.
- 회사 Team이나 Enterprise 플랜이라면 조직 관리자(Owner)만 커넥터를 추가할 수 있습니다. 관리자가 Creagen을 추가하면 구성원은 커넥터 화면에서 **연결**만 누르고 각자 로그인합니다.

### Claude 앱에서 확인하기

Claude 앱으로 돌아와 같은 실습 폴더로 **새 세션**을 열고, 아래 문장을 붙여 넣습니다.

```text
Creagen 연결 상태를 확인해줘. 연결이 안 되어 있거나 로그인이 필요하면 내가 화면에서 무엇을 눌러야 하는지 쉽게 알려줘.
```

Claude가 로그인이 필요하다고 하면 입력창에 아래를 붙여 넣고 Enter를 누릅니다. 연결 목록이 열리면 **Creagen**을 고르고 로그인합니다.

```text
/mcp
```

- 목록에 Creagen이 없으면 **새 세션**을 열고 다시 확인합니다. 세션은 시작할 때 연결 목록을 불러옵니다.
- 한 번도 쓰지 않은 연결은 목록 아래쪽에 접혀 있을 수 있습니다.

### 방법 2. Claude에게 대신 추가 맡기기 (방법 1이 안 될 때만)

대부분은 방법 1로 충분합니다. 회사 플랜이라 커넥터를 추가할 권한이 없을 때처럼 방법 1이 안 되면 Code 탭에 아래 문장을 붙여 넣습니다.

```text
이 실습 폴더에서만 쓰도록 Creagen 연결을 추가해줘. 주소는 https://agent.vcat.ai/api/mcp/creagenOfficialMCPServer/mcp 야. 끝나면 내가 로그인하는 방법을 알려줘.
```

**방법 1과 방법 2 중 하나만 씁니다.** 둘 다 등록하면 방법 2가 우선하고 방법 1의 연결은 숨겨집니다. 방법 2 쪽이 로그인 전이면 계속 "로그인 필요"로 남습니다.

<details>
<summary>터미널을 쓰는 분을 위한 명령</summary>

이 프로젝트 폴더에서 실행합니다. 모든 폴더에서 쓰려면 `--scope user`를 붙입니다.

```bash
claude mcp add --transport http creagen https://agent.vcat.ai/api/mcp/creagenOfficialMCPServer/mcp
```

`claude`를 실행하고 `/mcp` → **creagen** → **Authenticate**로 로그인합니다. 지울 때는 `claude mcp remove creagen`을 실행합니다. Claude에 추가한 커넥터가 Code 탭에 안 보이면 `/status`로 Claude 구독 계정으로 로그인했는지 확인합니다.

</details>

## 연결 확인

Code 탭 대화창에 아래 문장을 붙여 넣습니다. 조회만 하므로 크레딧을 쓰지 않습니다.

```text
Creagen 연결을 확인해줘. 읽기 전용 도구만 쓰고 등록, 생성, 변경은 하지 마.
내 계정 → AdCatch 워크스페이스 → 브랜드 → 경쟁사 → 광고 검색 5건 → 광고 1건 상세 순서로 확인해줘.
```

| 순서 | Claude가 확인하는 것 | 이렇게 나오면 정상 |
|---|---|---|
| 1 | 연결된 계정 | 내 이메일 |
| 2 | AdCatch 작업 공간 | 1개 이상 |
| 3 | 등록된 브랜드 | 1개 이상 |
| 4 | 브랜드의 경쟁사 | 목록이 나옴. 0개여도 연결은 정상 |
| 5 | 광고 검색 | 광고 목록과 전체 건수 |
| 6 | 광고 1건 상세 | 광고의 시작 방식, 화면 구성, 원본 영상 정보 |

- 1~3번까지 되면 연결은 정상입니다.
- 6번까지 되면 AdCatch 광고 찾기도 정상입니다.
- 브랜드가 0개면 아래 문장을 붙여 넣어 등록합니다.

```text
AdCatch에 내 브랜드 [브랜드 이름]와 경쟁사 [경쟁사 이름]를 등록하고 싶어. 필요한 정보가 있으면 물어보고, 무엇이 바뀌는지 먼저 보여준 뒤 내가 확인하면 등록해줘.
```

연결이 끝나면 [참고 영상 한 편을 내 제품 광고로 다시 만들기](video-remake.md)나 실습 앱 [STEP 2](../STEP.md#step-2-참고-광고)로 넘어갑니다.

## 요금제

**결제는 테스트 목적이라면 Creator 플랜을 추천드립니다.** 커넥터 연결은 무료이고, 이미지와 영상을 만들 때만 크레딧이 쓰입니다. Creator는 가장 낮은 금액으로 월 1,000 크레딧을 받아 연결 확인과 시험 생성에 알맞습니다.

| 플랜 | 월간 결제 | 연간 결제 (40% 할인) | 월 크레딧 | 요금 페이지의 생성량 안내 |
|---|---|---|---|---|
| **Creator (추천)** | 21,000원 | 월 12,600원 (연 151,200원) | 1,000 | 모델에 따라 영상 약 30개, 이미지 약 250개 |
| Creator Pro | 49,000원 | 월 29,400원 (연 352,800원) | 2,500 | 모델에 따라 영상 약 80개, 이미지 약 650개 |
| Enterprise | 영업팀 문의 | 영업팀 문의 | 협의 | 협의 |

요금 페이지의 생성량은 모델과 길이에 따라 크게 달라지는 대략적인 안내입니다. **이 실습처럼 사람과 제품이 나오는 10초 영상은 훨씬 많은 크레딧이 듭니다.** 실제 견적 예시입니다 (2026년 10월 23일, 크레딧이 빠지지 않는 견적 조회).

| 만들 것 | 견적 | Creator 1,000 크레딧으로 |
|---|---|---|
| 10초 영상, 정사각형, 일반 화질(720p) | 585 크레딧 | 한 달에 1편 |
| 5초 영상, 같은 설정 | 295 크레딧 | 한 달에 3편 |
| 10초 영상, 고화질(1080p) | 1,440 크레딧 | 만들 수 없음 (Creator Pro 필요) |

- **테스트는 월간 결제로 시작합니다.** 연간 할인은 런칭 프로모션이지만 1년 단위 결제입니다.
- **추가 크레딧(크레딧 팩)은 Creator Pro 구독자만 살 수 있습니다.** Creator에서 크레딧이 모자라면 다음 달을 기다리거나 업그레이드합니다.
- 기술 문제로 생성이 실패하면 빠진 크레딧은 자동으로 돌아옵니다.
- 유료 플랜으로 만든 이미지와 영상은 상업적으로 쓸 수 있습니다. 다른 사람의 얼굴, 상표, 저작물은 따로 주의합니다.
- 부가세 포함 여부와 플랜별 AdCatch 이용 범위는 요금 페이지에 적혀 있지 않습니다. 결제 화면이나 Creagen 고객센터에서 확인합니다.
- 가격은 2026년 10월 23일 [요금제 페이지](https://creagen.vcat.ai/pricing) 기준입니다. 결제 전에 최신 가격을 확인하세요.

## 자주 막히는 곳

| 상황 | 해결 |
|---|---|
| Creagen이 연결 목록에 없음 | 새 세션을 열고 다시 확인합니다. 그래도 없으면 방법 1의 추가 단계를 다시 하고, Claude 웹과 Claude 앱이 같은 계정인지 확인합니다. |
| 계속 "로그인 필요"로 나옴 | `/mcp`에서 Creagen을 고르고 로그인합니다. Creagen 웹사이트에만 로그인하면 Claude에는 권한이 넘어가지 않습니다. |
| Creagen이 두 개 보이거나 하나가 계속 로그인 필요 | 방법 1과 방법 2를 모두 쓴 경우입니다. `방법 2로 추가한 Creagen 연결을 지워줘`라고 붙여 넣습니다. |
| 로그인 후 화면이 멈춤 | 창을 닫고 Claude 설정의 커넥터 화면에서 Creagen의 **연결**을 다시 누릅니다. 주소창의 주소는 대화창에 붙여 넣지 않습니다. |
| 로그인이 풀렸다는 오류 | 시간이 지나 로그인이 만료된 것입니다. `/mcp`에서 다시 로그인합니다. |
| 브랜드가 0개 | 위의 브랜드 등록 문장을 붙여 넣습니다. |
| 광고 검색 결과가 0건 | 조건이 너무 좁거나 아직 모이지 않은 광고입니다. `조건을 하나씩 줄여서 다시 찾아줘`라고 붙여 넣습니다. |
| 다른 팀 자료가 보임 | 작업 공간이 여러 개입니다. `내 개인 작업 공간으로 다시 조회해줘`처럼 어느 곳을 쓸지 알려 줍니다. |

## 안전하게 쓰기

- **만들기는 견적부터.** 이미지와 영상 만들기는 크레딧을 씁니다. Claude가 견적과 남은 크레딧을 먼저 보여주고 내가 승인한 뒤 만들게 합니다.
- **AdAgent는 실제 광고를 바꿉니다.** 캠페인 상태, 하루 예산 변경, 광고 등록 도구는 실제 집행과 비용에 영향을 줍니다. 분명히 요청할 때만 쓰게 합니다.
- **AdCatch 등록은 계정 설정을 바꿉니다.** 브랜드와 경쟁사 등록, 계정 연결, 사이트 분석 시작은 필요할 때만 요청합니다.
- **성과 표시는 매출이 아닙니다.** AdCatch의 성과 등급은 관찰한 신호이며 실제 매출이나 광고 수익률이 아닙니다.
- **비밀번호, 키, 로그인 주소를 대화에 붙여 넣지 않습니다.** 연결은 위의 로그인 절차로만 합니다.
- 실습 참가자는 각자 자기 Creagen 계정으로 로그인합니다. 보이는 작업 공간, 브랜드, 경쟁사도 각자 계정 기준입니다.
