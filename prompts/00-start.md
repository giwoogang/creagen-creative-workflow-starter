# 실습 시작

아래 요청을 Codex 또는 Claude Code에 입력합니다.

```text
README.md와 AGENTS.md, docs/workshop.md를 읽고 광고 제작 실습을 안내해줘.
우선 샘플 모드로 시작할게. examples의 가상 설정을 사용해줘.

work 폴더를 만들고, 기존 결과가 있으면 덮어쓰지 말고 진행 상태를 먼저 확인해줘.
현재 연결된 도구로 가능한 일과 실제 이미지가 없어 진행할 수 없는 일을 나눠 알려줘.
외부 인증 정보나 과거 다른 작업의 브랜드 자료는 가져오지 마.

1단계 준비부터 진행하고 단계가 끝날 때 입력, 결과 파일, 다음 작업을 짧게 알려줘.
실제 생성은 별도로 요청할게. 지금은 분석과 프롬프트를 만들어줘.
```
