# 제품과 인물 준비

```text
실습 1단계를 진행해줘.
샘플 모드이면 examples/brand.example.json과 examples/assets.example.json을 읽고
work/brand.json과 work/assets.json을 준비해줘.
rules/creative-rules.md는 work/creative-rules.md로 복사해줘.
이미 해당 파일이 있으면 사용자 입력을 보존해줘.

내 브랜드 모드이면 내가 제공한 제품 설명과 파일만 사용해줘.
제품 정면 이미지와 인물 이미지의 실제 파일 위치, 역할과 사용 범위를 목록에 적어줘.
파일이 없으면 missing으로 남기고 경로나 에셋 ID를 만들지 마.

제품 이름, 확인된 사실, 쓸 수 있는 표현, 쓰면 안 되는 표현을 정리해줘.
브랜드와 모델의 등록 정보가 준비됐는지와 실제 생성 준비가 됐는지는 구분해줘.
```
