# 확장 실습 03단계: 이미지 광고 만들기

```text
확장 실습 03단계를 진행해줘.
work/brand.json, work/assets.json, work/references.json, work/creative-rules.md를 읽어줘.

이미지 참고 자료를 훅, 문제, 제품 역할, 근거, CTA로 나누고
본 것과 해석을 구분해 work/narrative-image.md에 적어줘.
샘플 설명만 있다면 실제 이미지를 분석한 것으로 쓰지 마.

이 구성을 우리 제품에 맞춰 work/image-prompts.md에 이미지 생성 문장으로 저장해줘.
참고 이미지의 구도와 배치는 따라도 되지만 문구, 로고, 상표, 제품, 인물 얼굴은 우리 것으로 바꿔줘.
제품 참조, 인물 사용 여부, 구도, 배경, 제품 이름, 카피와 CTA를 명시해줘.
제품 이름은 work/brand.json의 product_name을 써줘. 샘플 도해의 영문 라벨 글자는 그림의 일부라 카피의 제품 이름으로 쓰지 마.
병과 라벨을 보존하고 확인되지 않은 효능, 할인, 판매처 추천 표시는 넣지 마.
첫 이미지 1안과 훅만 다른 추가 후보 3개를 image-01, image-02, image-03, image-04처럼 이름 붙여 작성해줘.

실제 생성 요청과 입력 이미지가 없으면 생성 문장까지 완료하고 생성 상태는 pending으로 남겨줘.
내가 대화창에서 만들어 달라고 하면 현재 모델 규격, 생성 수, 견적과 남은 크레딧을 먼저 보여주고 멈춰.
내가 승인하면 요청 범위대로 실행하고 결과 파일과 설정을 work/generation-log.json에 기록해줘.
generation-log.json의 각 항목에는 kind(image 또는 video)를 적어 영상 기록과 구분해줘.
```
