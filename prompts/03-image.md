# 이미지 광고 만들기

```text
실습 3단계를 진행해줘.
work/brand.json, work/assets.json, work/references.json, work/creative-rules.md를 읽어줘.

이미지 참고 자료를 훅, 제품 제안, 근거, CTA로 나누고
관찰한 내용과 해석을 구분해 work/narrative-image.md에 적어줘.
샘플 설명만 있다면 실제 이미지를 분석한 것으로 쓰지 마.

이 구조를 우리 제품에 맞춰 새로 작성해 work/image-prompts.md에 저장해줘.
제품 참조, 인물 사용 여부, 구도, 배경, 제품 이름, 카피와 CTA를 명시해줘.
병과 라벨을 보존하고 확인되지 않은 효능이나 할인은 넣지 마.
첫 이미지 1안과 훅만 다른 추가 후보 3개를 작성해줘.

실제 생성 요청과 입력 이미지가 없으면 프롬프트까지 완료하고 생성은 pending으로 남겨줘.
생성을 요청한 경우에는 현재 모델 규격, 생성 수, 견적과 잔여 크레딧을 먼저 보여주고 멈춰.
내가 승인하면 요청 범위대로 실행하고 결과 파일과 설정을 work/generation-log.json에 기록해줘.
```
