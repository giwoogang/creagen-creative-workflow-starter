# 확장 실습 04단계: 참고 영상 분석

참고 영상을 장면마다 정밀하게 분석하는 단계입니다. 분석만 하므로 영상 생성 도구(연결 확인, 모델 조회, 업로드, 견적, 생성)는 부르지 않고 크레딧도 쓰지 않습니다.

```text
확장 실습 04단계를 진행해줘. AGENTS.md를 읽고 그 규칙을 지켜줘.
실습 앱 요청을 지정했다면 해당 context.json의 references와 videoOptions를 읽어줘.
그 요청에 선택된 광고만 쓰고 다른 요청이나 브랜드의 자료와 섞지 마.
수동 확장 실습이라면 work/references.json의 영상 자료를 써줘.

실제로 접근 가능한 영상, 자막 또는 장면 설명만 분석해줘.
원본 영상이 있으면 docs/video-remake.md의 ④ 분석 절차대로 받아서 장면을 나누고 화면을 직접 봐줘.
원본 영상의 저장 위치는 AGENTS.md를 따라줘.
AdCatch 자료는 읽기 전용으로 확인할 수 있지만 영상 생성 도구는 부르지 마.
샘플 모드에서는 가상 스토리보드 분석이라고 표시해줘.

분석은 실습 앱 요청이면 그 요청 폴더의 video-analysis.md에, 수동 확장 실습이면 work/video-analysis.md에 저장해줘.
맨 위에 분석한 reference_id를 적어줘.
장면마다 시작과 끝 시간, 역할, 카메라(거리, 각도, 움직임), 화면 배치, 인물 동작, 화면 문구의 위치, 대사 요약을 표로 정리해줘.
그다음 아래를 답해줘.
1. 첫 장면이 어떤 관심을 만드는가
2. 제품이 언제 어떤 역할로 등장하는가
3. 무엇을 보여주거나 근거로 제시하는가
4. 마지막에 어떤 행동을 요청하는가
5. 우리 광고에서 그대로 따를 것(화면 구성, 카메라, 동작, 장면 길이)과 우리 것으로 바꿀 것(인물, 제품, 문구, 로고)
6. 실제로 확인한 자료와 확인하지 못한 부분은 무엇인가

UGC라는 단어가 검색됐다는 이유만으로 UGC 형식이라고 쓰지 마.
실제 영상이나 AdCatch에 저장된 분석에서 확인한 근거와 출처를 남겨줘.
썸네일이나 광고 문구만 봤으면 영상 전체를 분석했다고 쓰지 마.
원본에서 본 컷 수와 우리 영상에 제안하는 컷 구성은 구분해줘.
실제 원본 시간을 확인하지 못했다면 임의로 만들지 마.
원본의 대사와 화면 문구는 통째로 옮기지 말고 역할과 길이만 요약해줘.

실습 앱의 video-plan.json은 로컬 편집 초안이며 원본의 관찰 결과가 아니야.
실습 앱 요청이면 referenceReview와 각 컷의 referenceObservation을 확인한 범위만 보완하고,
확인하지 못한 장면은 미확인으로 남겨줘. video-plan.json의 생성 상태는 not_started 그대로 둬줘.
수동 실습의 분석 파일에는 생성 상태를 적지 않아도 돼.
```
