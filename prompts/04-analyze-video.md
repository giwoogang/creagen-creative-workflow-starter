# 참고 영상의 이야기 분석

영상 제작 패키지를 보완하기 위한 분석 단계입니다. 이번 작업에서는 영상 생성 서비스의 MCP/API 연결, 조회, 업로드, 견적과 생성을 호출하지 않습니다.

```text
AGENTS.md를 읽고 영상 준비 범위를 지켜줘.
웹앱 요청을 지정했다면 해당 context.json의 references와 videoOptions를 읽어줘.
그 요청에 선택된 광고만 사용하고 다른 요청이나 브랜드의 자료와 섞지 마.
수동 확장 실습이라면 work/references.json의 영상 자료를 사용해줘.

실제로 접근 가능한 영상, 자막 또는 장면 설명만 분석해줘.
AdCatch 자료는 읽기 전용으로 확인할 수 있지만 영상 생성 서비스는 호출하지 마.
샘플 모드에서는 가상 스토리보드 분석이라고 표시해줘.

분석을 웹앱 요청 폴더의 video-analysis.md에 저장해줘.
수동 확장 실습의 저장 위치는 work/video-analysis.md야.
1. 첫 장면이 어떤 관심을 만드는가
2. 제품이 언제 어떤 역할로 등장하는가
3. 무엇을 보여주거나 근거로 제시하는가
4. 마지막에 어떤 행동을 요청하는가
5. 실제로 확인한 자료와 확인하지 못한 부분은 무엇인가

UGC라는 단어가 검색됐다는 이유만으로 UGC 형식이라고 쓰지 마.
실제 영상이나 저장된 분석에서 확인한 근거와 출처를 남겨줘.
썸네일이나 광고 문구만 봤으면 영상 전체를 분석했다고 쓰지 마.
관찰된 원본의 컷 수와 우리 영상에 제안하는 컷 구성은 구분해줘.
실제 원본 타임코드를 확인하지 못했다면 임의로 만들지 마.

웹앱의 video-plan.json은 로컬 편집 초안이며 원본의 관찰 결과가 아니야.
referenceReview와 각 컷의 referenceObservation은 확인한 범위만 보완해줘.
확인하지 못한 장면은 미확인으로 남기고 생성 상태는 not_started를 유지해줘.
대사나 구도를 복사하기보다 컷이 맡는 역할을 설명해줘.
```
