# 확장 실습 06단계: 같은 자료로 영상 3안 만들기

06단계는 두 번 할 수 있습니다. 처음에는 첫 장면(훅)만 다른 3안을 만듭니다. 다음 실험 설계는 07단계에서 성과를 읽은 뒤에 합니다. 07단계를 하기 전에는 다음 실험 안을 미리 만들지 않습니다.

## 처음 할 때

```text
확장 실습 06단계를 처음으로 진행해줘.
work/storyboard.md, work/video-prompts.md, work/creative-rules.md, work/references.json을 읽어줘.

제품, 인물, 본문, CTA, 전체 길이는 그대로 두고 첫 훅만 바꾼 3안을 만들어줘.
variant-a는 질문형, variant-b는 사용 상황형, variant-c는 제품 시각형으로 구성해줘.
아직 07단계를 하지 않았으니 다음 실험 안은 만들지 마.
work/variants.json에 variant_id, reference_id, 가설, 바꾼 것, 고정한 것,
생성 문장 파일, 생성 상태와 결과 경로를 기록해줘.
work/video-prompts.md에 각 안의 생성 문장을 연결해줘.

이번 단계는 변형 계획과 생성 문장만 준비해줘.
영상 생성 도구의 연결 확인, 모델 조회, 업로드, 견적, 생성은 하지 마.
영상을 실제로 만들고 싶으면 내가 대화창에서 따로 요청할게.
그때 쓸 도구와 견적, 남은 크레딧을 먼저 보여주고 내 승인을 기다려줘.

work/generation-log.json에는 실제 진행 상태를 기록해줘. 각 항목에는 kind(image 또는 video)를 적어줘.
아직 만들지 않은 것은 pending, 만드는 중은 running, 결과 파일이 있을 때만 completed로 적어줘.
응답이 늦다는 이유로 같은 요청을 새로 생성하지 마.
```

## 07단계를 마친 뒤 다시 할 때

```text
확장 실습 06단계를 다시 진행해줘.
work/rule-changes.md와 work/creative-rules.md에서 수정한 가설을 읽고,
그 가설에서 정한 요소 하나만 바꾼 새 3안을 round02-a, round02-b, round02-c로 만들어줘.
variant-a, variant-b, variant-c와 그 결과는 지우거나 고치지 마.
work/variants.json에 새 안의 가설, 바꾼 것, 고정한 것을 추가하고 이전 성과와 섞지 마.
영상 생성 도구는 부르지 말고 계획과 생성 문장까지만 해줘.
```

## 결과가 있을 때

```text
만든 영상이 있으면 제품과 인물 일관성, 손과 동작, 카피, 컷 연결을 확인해줘.
확인하지 못한 항목은 미확인으로 남겨줘.
모델, 생성 문장, 실제 옵션, 요청 ID와 결과 파일을 work/generation-log.json에 남겨줘.
```
